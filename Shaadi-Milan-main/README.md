# Shaadi Milan — Admin Panel

A production-grade Next.js 15 + React Query admin panel for the Shaadi Milan matrimony application.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | Next.js 15 (App Router) |
| Data Fetching | TanStack React Query v5 |
| State Management | Zustand (auth store) |
| Database / Auth | Firebase (Firestore + Auth) |
| Styling | Tailwind CSS v4 |
| Charts | Recharts |
| Language | TypeScript |

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000

## Features
1. Dashboard — Live stats & charts
2. Monthly Reports — Full analytics with export
3. Weekly Reports — Agent payout calculations
4. Agent Performance — Pan India conversion tracking
5. User Management — Filterable Male/Female/Agent directory
6. Registration Control — Approve/Reject with one click
7. Profile Management — Edit any user with admin authority
8. Agent Management — Register & generate unique Agent IDs
9. Orders & Payments — Full transaction ledger
10. Notifications — Targeted messaging to any user group
11. Settings — Admin, payment, Firebase & export config
